TOPIC
    about_Bsn.Host

SHORT DESCRIPTION
    Host-level terminal session recording for PowerShell, capturing
    full-screen TUI applications into replayable asciicast v2 files.

LONG DESCRIPTION
    The Bsn.Host module is the BSN counterpart of Microsoft.PowerShell.Host:
    it covers the host/transcript domain. Its first cmdlet,
    Start-InteractiveTranscript, records what Start-Transcript cannot: the
    terminal session itself, including full-screen interactive TUI
    applications such as sconfig, vim, htop or nmtui.

    The recorded command runs inside a pseudo-terminal whose output stream
    is proxied to the real console and recorded with timestamps into an
    asciicast v2 (.cast) file that plays back with:

        asciinema play <file>.cast

  RECORDING OPTIONS (RFC 421 SEMANTICS)

    -RecordingFormat selects the deliverable: Asciicast (default, .cast
    only), Gif (rendered via the external 'agg' renderer), WebM and Mp4
    (rendered via 'agg', transcoded via 'ffmpeg'). The .cast file is
    always written and remains the source of truth; when a rendering tool
    is missing, a warning is emitted and the cast stays complete.

    -RecordIdleTimeLimit compresses idle gaps longer than the limit (in
    seconds) in the cast timing, keeping long, idle-heavy sessions
    watchable. Zero (default) preserves original timing.

    -RecordInput additionally records keystrokes as 'i' events (Windows
    only in this release). It is off by default because it can capture
    secrets typed at hidden prompts; when enabled, the fact is noted in
    the cast file header.

    Console resizes during a recording are forwarded to the pseudo console
    and recorded as 'r' events, so full-screen TUI applications that
    re-query the terminal size replay correctly.

  PLATFORM SUPPORT

    Windows: ConPTY pseudo-console (requires Windows 10 1809+); optional
             keystroke recording via -RecordInput.
    Linux:   script(1) with exact timing (util-linux).
    macOS:   script(1) with approximated timestamps (BSD script).

  SCENARIOS

    - Audit and compliance records of privileged interactive sessions
    - Support and incident response: reproduce exactly what was on screen
    - Training material and shareable session captures

  BACKGROUND

    Implements the community request tracked in
    https://github.com/PowerShell/PowerShell/issues/28353 at the scope a
    PowerShell Gallery module can deliver. Transparent recording of the
    entire host session is only possible from inside the host itself; this
    module instead records a nested session, which captures every child
    process launched within it, including TUI applications.
